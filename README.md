# CallTime

Stage countdown timer for live events. A clean operator panel plus a full-screen output for the stage or green room.

Free forever, no account required. Part of the [OnQue](https://onque.io) free tools.

## Download

Current version: **1.2.0**

- **Windows:** [calltime-setup-win-1.2.0.exe](https://github.com/OnQue-Tools/CallTime/releases/download/v1.2.0/calltime-setup-win-1.2.0.exe)
- **macOS (Apple Silicon):** [calltime-mac-arm64-1.2.0.dmg](https://github.com/OnQue-Tools/CallTime/releases/download/v1.2.0/calltime-mac-arm64-1.2.0.dmg)

All versions are on the [Releases page](https://github.com/OnQue-Tools/CallTime/releases).

The macOS build is for Apple Silicon (M1 and later). On first open, allow it under **System Settings → Privacy & Security**.

## What it does

- Operator panel plus a separate full-screen output window
- Countdowns by typing MM:SS, 5m30s or quick presets, with flash messages and red overtime
- Control other CallTimes on your network from one touch screen, with show presets that cue every machine at once
- Stream Deck control through Bitfocus Companion
